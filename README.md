# MCoffee - Premium Coffee Ordering & Rewards iOS App

Feature-packed mobile coffee ordering and loyalty iOS application with customizable beverage options, order tracking, cart checkout, and barista profiles.

---

## 🛠️ Tech Stack & Architecture
`SwiftUI` `UIKit Integration` `CocoaPods` `ObservableObject` `JSON Caching`

- **Platform:** iOS 16.0+
- **Language:** Swift 5.10+
- **Framework:** SwiftUI
- **Architecture:** MVVM / Clean Architecture

---

## ✨ Key Features
- Rich coffee menu (Americano, Cappuccino, Flat White, Latte, Raf, Espresso)
- **Beverage customization**: cup size, milk types, syrups, and sweetness level
- Real-time order tracking interface and barista order status
- Saved payment methods and rewards balance tracking

---

## 🚀 Getting Started

### Prerequisites
- macOS Sonoma or newer
- Xcode 15.0 or newer
- iOS Simulator or physical device running iOS 16+

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/Devendrakumar16/Mcoffee-Ordering-App.git
   cd Mcoffee-Ordering-App
   ```
2. Open the project in Xcode:
   ```bash
   open *.xcodeproj 2>/dev/null || open *.xcworkspace
   ```
3. If CocoaPods is used:
   ```bash
   pod install
   open *.xcworkspace
   ```
4. Select your target simulator (e.g., iPhone 15 Pro) and press `Cmd + R` to build and run!
